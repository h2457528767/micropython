
## NUCLEO-C562RE 开发板

使用 STM32CubeProgrammer 软件烧录。

## 固件的完整外设-引脚对应表

**GPIO / LED**

| 功能         | 引脚    | Python                       |
| ------------ | ------- | ---------------------------- |
| 板载绿灯 LD1 | **PA5** | `Pin(("gpioa", 5), Pin.OUT)` |

**UART（2 路可用）**

| 外设         | 引脚            | Python 设备名             |
| ------------ | --------------- | ------------------------- |
| USART2 TX/RX | **PA2 / PA3**   | `UART("serial@40004400")` |
| USART1 TX/RX | **PB14 / PB15** | `UART("serial@40013800")` |

**I2C（1 路）**

| 外设         | 引脚          | Python                             |
| ------------ | ------------- | ---------------------------------- |
| I2C1 SCL/SDA | **PB6 / PB7** | `I2C("i2c@40005400", freq=400000)` |

**SPI（1 路，deferred）**

| 外设               | 引脚                        | Python                |
| ------------------ | --------------------------- | --------------------- |
| SPI1 SCK/MISO/MOSI | **PA5 / PA6 / PA7**，CS=PC9 | `SPI("spi@40013000")` |

**ADC（adc1 + adc2 共 6 通道）**

| 通道     | 引脚    | Python                     |
| -------- | ------- | -------------------------- |
| adc1 ch0 | **PA0** | `ADC(("adc@42028000", 0))` |
| adc1 ch1 | **PA1** | `ADC(("adc@42028000", 1))` |
| adc1 ch6 | **PA6** | `ADC(("adc@42028000", 6))` |
| adc1 ch8 | **PC0** | `ADC(("adc@42028000", 8))` |
| adc2 ch5 | **PC5** | `ADC(("adc@42040000", 5))` |
| adc2 ch6 | **PB0** | `ADC(("adc@42040000", 6))` |

**PWM**

| 通道            | 引脚    | Python                                |
| --------------- | ------- | ------------------------------------- |
| PWM1 CH3 (TIM1) | **PA5** | `PWM(("pwm", 3), freq=…, duty_u16=…)` |

**传感器（zsensor）**

| 传感器           | 接口              | Python                                                      |
| ---------------- | ----------------- | ----------------------------------------------------------- |
| 芯片结温 dietemp | adc1 ch12（内部） | `zsensor.Sensor("dietemp")` → `get_float(zsensor.DIE_TEMP)` |
| DHT11 dht11      | **PA4** 单总线    | `zsensor.Sensor("dht11")` → `AMBIENT_TEMP` / `HUMIDITY`     |
| VREF 内部基准    | adc1 ch13（内部） | 供 ADC 换算，不直接用                                       |

## 引脚冲突

| 引脚    | 冲突项                          | 说明                                                         |
| ------- | ------------------------------- | ------------------------------------------------------------ |
| **PA5** | LED GPIO / SPI1-SCK / PWM1-CH3  | 三者同脚；SPI1 一旦构造就抢走 PA5（PWM/LED 失效），同会话别混用 |
| **PA6** | ADC1-ch6 / SPI1-MISO            | SPI1 构造后 ADC ch6 失效                                     |
| **PA4** | DHT11 / DAC1-OUT1（DAC 未启用） | 当前无冲突                                                   |
| **PA7** | SPI1-MOSI 独占                  | 无冲突                                                       |
